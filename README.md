A make.fun entry for the **Rename the Planet** bounty: one funny new name
for a planet in our solar system, plus the why, in a single line.

> Rename Saturn 'Buffering' -- it's been loading its rings for 4.5 billion years and the bar hasn't moved.

## Run

```sh
python3 main.py
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default).
